# Toluwalase Iyekolo | Portfolio

The personal portfolio website of **Toluwalase Iyekolo**, a Lagos-based creative working in brand storytelling, communications, marketing and video editing.

**Live site:** (https://tolu-portofolio.vercel.app/)

**Contact:** [iyekolotoluwalase@gmail.com](mailto:iyekolotoluwalase@gmail.com) · [LinkedIn](https://www.linkedin.com/in/toluwalase-iyekolo)

## What's on the site

- **Projects:** Girls Beyond Limit 2.0, GOtv Jam Festival and BBN Prize Presentation, each opening in a pop-up with further details.
- **Video content:** brand videos that play inside the site.
- **Viral posts:** social posts created for NBG Africa.
- **Personal brand content posts:** content creation and creative execution for personal brand Instagram pages.
- **Editorial and blog writing:** written editorial samples, readable on the site.
- **Tools:** the tools used to plan, create and publish content.
- A hamburger menu on phones, smooth animations, and a layout that adapts to any screen size.

## How it is built

A hand-written static website using plain HTML, CSS and JavaScript. There is no framework and no build step, and it is hosted on Vercel.

```
index.html          page structure
css/style.css       all the design
js/content.js       the content: projects, videos, posts and articles
js/main.js          pop-ups, video player and phone menu
images/             photos, covers and tool logos
presentations/      project documents (PDF)
```

## Updating the content

Open `js/content.js`, change the text, links or image names, and commit the change. Vercel redeploys the site automatically.

## Running it locally

Open `index.html` in a browser. Instagram videos only play on the live site, because Instagram blocks them when a page is opened straight from a computer.

## Deploying

Import this repository in [Vercel](https://vercel.com) and click Deploy. No settings need changing.
